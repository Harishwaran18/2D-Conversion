How to use

  1. Open scans — DICOM files or a ZIP of them, NIfTI, or plain images (PNG/JPEG).
  2. Find the window — use the presets, or drag the centre/width sliders.
  3. Segment — Otsu is automatic; switch to manual to tune the threshold.
  4. Export 2D — trace outlines at true millimetre scale as SVG, PDF sheets or PNG.
  5. 3D print — smooth, simplify and hollow, then save an STL or the sections.
